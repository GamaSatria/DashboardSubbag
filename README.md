# Mockup Dashboard Keuangan Perencanaan Klinik

Repositori ini berisi mockup antarmuka untuk Dashboard Keuangan Perencanaan Klinik.

## Fitur Mockup
- Dashboard interaktif monitoring keuangan dan perencanaan klinik.
- Ekspor data (SheetJS / xlsx).
- Standalone HTML (dapat dijalankan langsung di browser atau melalui GitHub Pages).

## Cara Menjalankan
Buka file `index.html` langsung di peramban web (browser).
